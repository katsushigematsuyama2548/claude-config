# 新規ファイル作成前の確認規約

## Overview

古い学習データだけを頼りに実装してはならない。
ライブラリ・サービスの API は頻繁に変わる。公式情報を確認してから書く。

## 作成前に行うこと

1. 使用するライブラリ・サービスの**公式ドキュメント**で最新の API・設定値を確認する
2. バージョン依存の挙動がある場合は、実際のバージョンを確認してから書く

## Common Mistakes

**Bad: 学習データのまま実装**
```
# boto3 の古い API を使って実装 → 本番で動作しない
```

**Good: ドキュメント確認後に実装**
```
# 公式ドキュメントで boto3 最新 API を確認してから実装
```
