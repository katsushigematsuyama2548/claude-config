# プログラムファイルヘッダー規約

## Overview

ファイルの目的・変更履歴を冒頭に記録することで、後から見た人が「何のファイルか」「いつ・誰が・なぜ変えたか」を追跡できる。
後工程のレビュー・障害対応・引き継ぎの工数を下げるために必須とする。

## Quick Reference

### 新規作成時

ファイルの先頭にヘッダーを追加する。引数・戻り値は不要な場合は行ごと省略してよい。

**Python / Shell（`#` コメント）:**

```
#------------------------------------------------------------------------#
# システム名    : {システム名}
# ファイル名    : {ファイル名.拡張子}
# 処理概要      : {処理の目的を簡潔に記述}
# 引数          : 第1引数: {説明}
#                 第2引数: {説明}
# 戻り値        : 0:正常終了、9:異常終了
#
# 変更年月日    担当者        変更内容（特定可能なIDを付すこと）
# YYYY/MM/DD    matsuyama     新規作成
#------------------------------------------------------------------------#
```

**バッチファイル（`.bat`、`::` コメント）:**

```
::-----------------------------------------------------------------------::
:: システム名    : {システム名}
:: ファイル名    : {ファイル名.bat}
:: 処理概要      : {処理の目的を簡潔に記述}
:: 引数          : 第1引数: {説明}
:: 戻り値        : 0:正常終了、9:異常終了
::
:: 変更年月日    担当者        変更内容（特定可能なIDを付すこと）
:: YYYY/MM/DD    matsuyama     新規作成
::-----------------------------------------------------------------------::
```

### 変更時

変更履歴に1行追記する。内容は1行に収める。

```
# YYYY/MM/DD    matsuyama     {変更内容を1行で。チケット番号等の特定可能なIDを含めること}
```

## Common Mistakes

**Bad: 変更内容が曖昧**
```
# 2026/04/26    matsuyama     修正
```

**Good: 何を変えたか特定できる**
```
# 2026/04/26    matsuyama     クロスアカウント対応としてARNを引数化（#123）
```

---

**対象外ファイル:** `.js` `.ts` `.jsx` `.tsx` などフロントエンドファイルにはヘッダーを付けない。
